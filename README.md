# Pet Care Information System – Group 3

ICT305 Assessment 1 starter repository. The planned website uses HTML, CSS, JavaScript, Flask and SQLite. This package is a setup scaffold, not a completed MVP.

## Setup
1. Use Python 3.12 or later.
2. Create a virtual environment (`python -m venv .venv`).
3. Activate it, then `python -m pip install -r requirements-dev.txt`.
4. Run `python -m pytest -q`.

The starter check tests reminder date rules only. The Flask site, accounts, database and other stories have not been implemented.

See `WORKING_AGREEMENT.md`, `DEFINITION_OF_DONE.md`, `backlog.csv` and `SETUP_GUIDE.md`. Team members must review the files, agree on the plan and follow the institute's AI-use rules before committing them.
